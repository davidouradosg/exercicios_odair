# 10 Exercícios Práticos com Append em Python

Exercícios sobre o método `.append()`, que adiciona um elemento ao final de uma lista.

| Arquivo | Exercício |
|---|---|
| `exercicio_01.py` | Criando uma lista de frutas |
| `exercicio_02.py` | Números pares de 1 a 10 |
| `exercicio_03.py` | Entrada de dados do usuário |
| `exercicio_04.py` | Quadrado dos números |
| `exercicio_05.py` | Separando palavras por tamanho |
| `exercicio_06.py` | Adicionando uma lista dentro de outra |
| `exercicio_07.py` | Filtrando notas acima da média |
| `exercicio_08.py` | Invertendo uma lista manualmente |
| `exercicio_09.py` | Intercalando duas listas |
| `exercicio_10.py` | Acumulador de valores até uma condição |

## Como executar

```bash
python exercicio_01.py
```
